01 / Chọn hai file để đối chiếu

Hỗ trợ file nhị phân, văn bản, DLL, EXE, bytes…
Chọn đủ hai file để bắt đầu. Việc đọc và so sánh diễn ra ngay trên thiết bị của bạn.

Byte dùng hệ hex (00–FF). Offset nhận số thập phân hoặc tiền tố 0x để nhập hex. Dấu gạch ngang tạo khoảng, ví dụ 00-0F, A0-AF. Nếu file khác kích thước, vùng thiếu được đánh dấu EOF.
